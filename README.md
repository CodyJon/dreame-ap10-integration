# Dreame AP-10 Air Purifier Integration

Custom Home Assistant component for the Dreame AP-10 Air Purifier.

Features: Fan control, sensors (PM2.5, temp, humidity, filter life), switches, config flow UI.

## Installation via HACS (Recommended)

[![Open your Home Assistant instance and add this repository.](https://my.home-assistant.io/badges/hacs_repository.svg)](https://my.home-assistant.io/redirect/hacs_repository/?owner=CodyJon&repository=YOUR_NEW_REPO_NAME)

1. HACS → Integrations → ⋮ (top right) → Custom repositories
2. Paste repo URL: https://github.com/CodyJon/YOUR_NEW_REPO_NAME
3. Category: Integration
4. Add → search "Dreame" → Download → restart HA

## Manual Install
Copy the `dreame_airpurifier` (or your domain) folder to `<config>/custom_components/`.
Restart HA → Add Integration → search "Dreame".
